# Security policy

## Supported versions

Orbit has no release yet, so no version is supported for everyday use. Reports about the current `main` branch are welcome.

## Report a vulnerability

Please report privately, not in a public issue:

- Use GitHub's "Report a vulnerability" button on the Security tab of this repository, or
- Email novaegtech@gmail.com with "Orbit security" in the subject.

Include the steps to reproduce, the affected system and what an attacker could gain. We aim to reply within 7 days. We will tell you when a fix ships and credit you if you want that.

## Engine vulnerabilities

Orbit tracks stable CEF builds, which follow Chromium. A vulnerability in Chromium or CEF itself should go to those projects first:

- Chromium: https://www.chromium.org/Home/chromium-security/reporting-security-bugs/
- CEF: https://github.com/chromiumembedded/cef/security
