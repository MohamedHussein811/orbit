# Orbit design system

Orbit looks like one product across the browser frame, Settings and the other built-in pages, the
new tab page and Shields. Everything takes its colors from one set of tokens in
`tools/design/tokens.mjs`.

## Idea

The view from orbit: deep space above, a planet's lit edge, controlled light. Space shows in
accents: the new tab page's horizon, a soft glow behind page headings, the accent color. Controls
stay plain and readable. Motion is limited to one moment (the new tab page's horizon brightening
on load) and the faint twinkle of distant stars. Both stop when the system asks for reduced motion.

## Themes

| Theme | What it is | How it is built |
| --- | --- | --- |
| Space (default) | Deep navy surfaces, periwinkle accent | Orbit's palette in dark mode |
| Dark | Neutral graphite | Chromium's grey palette in dark mode |
| Light | Near-white surfaces, lavender frame | Orbit's palette in light mode |
| System | Space or Light, following the device | Orbit's palette, device mode |
| Custom accent | Any color, picked in Customize Orbit | Chromium's generated palette from that color |

People choose the theme in Settings > Appearance > Mode. The new tab page and Orbit's own pages
follow the browser: Space when the browser is dark, Light when it is light.

## Tokens

`tools/design/tokens.mjs` builds Orbit's tonal ramps (primary, secondary, tertiary, neutral,
neutral variant; the error ramp is Chromium's) for dark and light mode and writes:

- `chromium/overlay/ui/color/orbit_palette.inc`: Chromium's reference colors. `orbit-theme.patch`
  uses them in place of Chromium's default palette, so the frame, tabs, toolbar, address bar,
  menus, dialogs, side panel and WebUI pages all take them.
- `extension/src/shared/tokens.css`: the same values as CSS variables for the built-in pages.
- The contrast table below.

Error pages and security warnings get fixed values from the same palette in `orbit-pages.patch`.

Run `node tools/design/tokens.mjs check` to verify contrast and that the generated files are
current, and `node tools/design/tokens.mjs write` after changing a ramp.

## Type

Built-in pages use Readex Pro (SIL Open Font License), which covers Latin and Arabic, so both
scripts share one voice. Weights: 170 for the clock, 300 to 350 for reading text, 450 to 500 for
labels and headings. Native browser UI keeps the system font.

## Right to left

Built-in pages set `dir` from the browser language through `chrome.i18n` and use logical CSS
properties (`inset-inline`, `margin-inline`, `border-inline-start`), so Arabic mirrors the layout.
Web addresses and host names stay left to right. Text people type (notes) uses `dir="auto"`.

## Limits

- The new tab page cannot tell Space from Dark (both are dark to a web page), so in Dark it still
  shows the space scene. Its Customize panel offers a plain background instead.
- A custom accent changes the browser's palette but not the accent on Orbit's own pages yet.
- Windows and Linux frames are opaque. The translucent frame option in Chromium 157 is macOS only.
